# Recorded announcements

NetOn includes eight English voice recordings provided by Voltura AB:

- Internet is on.
- Internet is off.
- NetOn by Voltura AB.
- NetOn will start with Windows.
- NetOn will not start with Windows.
- Colors reset.
- Please select a foreground color.
- Please select a background color.

The recordings play locally without an internet connection. Select **Recorded voice - English** under **Settings → Voice** to use them. Installed Windows voices are also available.
