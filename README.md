# Voltura NetOn

Turn your PC's internet access on or off from the icon next to the clock.

**[Website](https://neton.voltura.se/)** · **[Download for Windows](https://github.com/voltura/voltura-neton/releases/latest)**

## Install

For Windows 10 and 11 (64-bit).

1. Download the Windows installer from the link above.
2. Run Setup and follow the steps. Leave **Start NetOn** checked to open it when Setup finishes.
3. Accept the Windows administrator prompt when NetOn starts.

## Use

- **Left-click the tray icon** to turn internet access on or off.
- **Right-click** for the Internet switch, scheduling, settings, and **Open NetOn**.
- **Green** means network connections are enabled. **Red** means all detected network connections are disabled. **Gray** means the status is unavailable.
- **Open NetOn** shows the main window, with a clickable switch, external IP address, and copy button.
- **Show connection details** expands the adapter dropdown and status information. The window opens with these details hidden.

OFF disables the PC's network connections, including Ethernet and Wi-Fi. ON restores the connections that were enabled before OFF. An enabled connection still needs an available network and internet service.

## Schedule

Choose **Schedule** from the tray menu to turn internet on or off after **10 minutes, 30 minutes, 1 hour, 2 hours, 4 hours, 8 hours, or 24 hours**.

The schedule shows a countdown and can be canceled or replaced. Keep NetOn running in the tray until the scheduled time. Choosing **Exit NetOn** cancels the schedule. If the PC sleeps past that time, the change runs when NetOn resumes. Manual switches leave the schedule in place.

## Settings

Open **Settings** from the main window or tray menu to choose:

- Light, Dark, or Follow Windows appearance.
- Recorded voice - English, or an installed Windows voice.
- Mute all sounds.
- Start with Windows.
- Colors for the on and off icons.

## Close NetOn

Closing the main window hides it to the tray. Choose **Exit NetOn** from the tray menu or main window to close the app.

Exiting leaves network connections in their current state. If they are off, open NetOn and turn them on to restore them.
